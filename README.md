# 자동차 경주

> 자동차 이름과 시도 횟수를 입력하면, 자동차 경주를 진행하고 승자의 이름을 출력하는 콘솔 애플리케이션

### 실행 방법
```shell
git clone https://github.com/bhoon716/kotlin-racingcar-8

cd kotlin-racingcar-8

./gradlew clean build
```

## 실행 과정

1. 경주할 자동차 이름 입력. (쉼표 기준으로 구분)
2. 시도할 횟수 입력
3. 실행 결과 출력
    1. 각 자동차 1회 전진 시도 진행
    2. 1회 결과 출력
    3. 시도 횟수만큼 진행
4. 최종 우승자 출력 (공동 우승 가능)

## 기능 요구 사항

- [ ] [출력] 자동차 이름 입력 문구 출력
- [ ] [입력] 자동차 이름 입력
- [ ] [기능] 경주할 자동차 생성
- [ ] [출력] 시도할 횟수 입력 문구 출력
- [ ] [입력] 시도할 횟수 입력
- [ ] [기능] 자동차 경주 생성
- [ ] [출력] 자동차 경주 실행 결과 문구 출력
- [ ] [기능] 각 자동차 랜덤 숫자(0~9) 생성
- [x] [기능] 랜덤 숫자가 4 이상이면 해당 자동차 한 칸 전진
- [ ] [출력] 각 라운드 진행 상황 출력
- [ ] [기능] 최종 우승자 판별
- [ ] [출력] 최종 우승자 이름 출력

## 예외 케이스

> 사용자가 잘못된 값을 입력할 경우, `IllegalArugmentException` 발생시킨 후 애플리케이션 종료

- [ ] 자동차 이름을 입력하지 않은 경우 (ex. "", "pobi,,jun" 등)
- [ ] 자동차 이름이 5자 이하가 아닌 경우 (ex. "pobipobi, woni" 등)
- [ ] 자동차 이름이 중복되는 경우(ex. "pobi", "woni", "pobi" 등)
- [ ] 시도 횟수가 자연수가 아닌 경우 (ex. 음수, 0, 실수)

## 추가한 기능 요구 사항

> 기능 요구 사항에 기재되지 않은 내용은 스스로 판단하여 구현한다.

- [ ] 시도 횟수의 범위는 최소값 1부터 최대값 1000 사이의 자연수이다.
- [ ] 자동차의 이름은 중복될 수 없다.
- [ ] 자동차의 이름은 문자와 숫자만 가능하다. (특수문자 불가능)

## 주요 프로그래밍 요구사항

- build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- 3항 연산자를 쓰지 않는다.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
    - 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- else, switch/case를 사용하지 않는다.
- 구현한 기능에 대한 단위 테스트를 작성한다. (UI 로직 제외)
